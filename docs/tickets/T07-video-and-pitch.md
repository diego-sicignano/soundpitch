# T07. Demo video and pitch

**Depends on:** T02 to T06 for whatever you show or name  **Acceptance:** none (checklist)  **Rules:** 4.4  **Judging:** criteria 3 and 4

## Goal

A public video under two minutes and a pitch text that names only the technologies actually used.

## Steps

1. `docs/submission/PITCH.md` is the submission text for the project as it stands (checked 2026-10-23) and names Microsoft Foundry, the Microsoft Agent Framework and GitHub Actions as used. Re-check it on the day: change a sentence only for a step that is really done. For each technology named, it points to the file that uses it.
2. Rehearse `docs/submission/DEMO_SCRIPT.md` against the local replay app (or the image); keep to about 110 seconds. A hosted URL is optional (D26).
3. Record with headphone-quality audio of the page (system audio) and a voice-over in English. No music. No Premier League or Microsoft logos on screen. Add captions to the video: this project is about accessibility.
4. Upload as public to YouTube or Vimeo. Open it signed out and check it plays.
5. Add the URL to `README.md` and the submission form.

## Done when

The video URL plays signed out, is under two minutes and is in the README.

## Out of scope

Editing effects, background music, translated versions.
