## False acceptance: false or unsupported text the verifier lets through

## False rejection: valid text the verifier turns away

The other risk. It costs naturalness, not trust, because the template fallback speaks instead. Denominators are explicit.

Hand-written commentary, all of it true. *Sentences* are distinct sentence patterns, each tried on every moment of its kind; *accepted on every moment* means no rejection at all. The last column counts sentence-on-moment pairs, so it is weighted by how often each kind of moment occurs.

## Fallback: what the listener hears

A deterministic describer says one sentence of the corpus for each moment it has a sentence for (sentence number = moment id modulo the number of sentences). A rejected sentence is not rescued by a retry, because the describer would repeat it, so the moment ends in the verified template. Moments without a sentence in the corpus are not counted.
